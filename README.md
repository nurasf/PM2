# Sistema de Gestão Kanban

Este projeto é um sistema Kanban desenvolvido como entrega final 2

## Membros do grupo

Nur Assaf

## Objetivo

Facilitar a organização de atividades e tarefas por meio de um painel.

## Funcionalidades

- Criar novos quadros (ex: “Projeto X”)
- Renomear e excluir quadros
- Coluna "Avisos" com edição de texto livre
- Adicionar, renomear e remover membros dos quadros
- Criar colunas e cartões (tarefas)
- Mover cartões entre colunas
- Persistência de dados com `localStorage`
